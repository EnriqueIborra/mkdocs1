    Publicar en GitHub¶

    1. Prepara clau  :   ssh-keygen -t ed25519 -C "tu-mail@correo.com"  ## el mail associat al teu compte de github
2. Puja la clau a github :  https://github.com/settings/keys   (C&P el text de la clau .pub) demana passphrase!
3. Canvia repositori:  git remote set-url origin git@github.com:tuusuario/tu-repo.git
4. Crea un repositori en GitHub. (tu-repo)
5. Puja el projecte:

    Puja el projecte: Dins de la carpeta mi-web¶

    git init
git add .
git commit -m "Primera versio"
git branch -M main
git remote add origin https://github.com/tuusuario/tu-repo.git
git push -u origin main   (demana passphrase)
mkdocs gh-deploy     (demana passphrase)

    Llest ! 🎉 Tens la teua web pública en:

    https://tuusuario.github.io/tu-repo/

    Ja està el VSCode configurat. Ara sols cal fer un "mkdocs gh-deploy" cada vegada que volem pujar els canvis a github
